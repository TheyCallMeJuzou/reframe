Download reframe

reframe is a free, open source desktop app for Claude Code. Every session is a tile in one window, and all of them stay in view: split, group and collapse them, give a group a window of its own, and save windows as workspaces. It takes over sessions running in other terminals, keeps sessions working in the background with a notification when Claude is done or needs you, and resumes every session after a restart. More about what it does.

Latest version: see the release page (release notes). You need Claude Code installed and logged in (claude on your PATH). From version 1.0 on, reframe is a native app, for Windows and (from 1.1 on) Linux; macOS keeps version 0.10 for now.

Windows

Installer (.exe)

For Windows 10 and 11. Installs for your user, without admin rights, also over an installed 0.x. Updates itself.

Portable (.zip)

Unpack anywhere and start reframe.exe. Keeps its data next to it and tells you about new versions.

macOS (version 0.10)

Disk image (.dmg)

For Apple silicon. Built with Electron in CI, not tested yet. Does not update to 1.x.

Linux

AppImage

For x86-64 with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 or later). Make it executable (chmod +x), then run it. Updates itself.

Debian package (.deb)

sudo apt install ./reframe_…_amd64.deb, also over 0.x's. Updated by installing the next one.

Older versions and every file of a release: GitHub Releases. Source code: GitHub.

Updating from 0.x

  • Windows, installed: reframe updates itself to 1.x when you quit it (or right away with Restart to update in the tray menu), keeping your sessions, windows, settings and shortcuts. Or run the installer over it.
  • Windows, portable: quit it (tray menu → Quit), unpack the new ZIP, and put the old copy's data folder next to the new reframe.exe. To move to the installed reframe instead, copy data\state.json into %APPDATA%\reframe (in place of the one there) before its first start.
  • Linux: an AppImage of 0.10 updates itself to 1.1 the same way, keeping your sessions, windows and settings (~/.config/reframe); a Debian package is updated by installing the new one over it. Quit 0.10 before you start 1.1 by hand.
  • macOS stays on 0.10, which does not update to 1.x.

The first start

The builds are not code-signed yet, so the first start needs a confirmation:

  • Windows installer: if SmartScreen warns, choose More info → Run anyway.
  • Windows, portable: before unpacking, right-click the ZIP → Properties → tick Unblock. Otherwise Windows marks every unpacked file as downloaded, and SmartScreen asks on the first start. The copy keeps its sessions, windows and settings in the folder data next to it and runs apart from an installed reframe. If you let it start with the system and move the folder later, turn that on again.
  • Linux: the tray needs a desktop that has one (KDE, Xfce, Ubuntu's GNOME; plain GNOME with its AppIndicator extension); without one, a window you close but keep is minimized instead.
  • macOS (0.10): drag reframe into Applications, then right-click it → Open the first time (or xattr -dr com.apple.quarantine /Applications/reframe.app). Updates on macOS need a signed build, so for now update by downloading the new version.

Uninstall

If you let reframe start with the system, the Windows uninstaller takes that out again (before version 0.6.0, turn it off first, in the tray menu); on Linux, turn it off in Settings before you remove reframe. reframe never changes Claude Code's own settings files, so there is nothing to undo there.

  • Windows installer: Settings → Apps → Installed apps → reframe → Uninstall. Your sessions, windows and settings stay in %APPDATA%\reframe; delete that folder to remove them too.
  • Windows, portable: quit reframe and delete its folder (its data is inside).
  • macOS: quit reframe and move it from Applications to the Trash. Its data is in ~/Library/Application Support/reframe.
  • Linux: delete the AppImage, or remove the package (sudo apt remove reframe). Its data is in ~/.config/reframe.

Code signing policy

reframe uses the SignPath Foundation for code signing: the Windows releases are going to be signed through its free code signing for open source projects (being set up; until then they are unsigned). Free code signing provided by SignPath.io, certificate by SignPath Foundation.
