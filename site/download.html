Download reframe

reframe is a free, open source desktop app for Claude Code. Every session is a tile in one window, and all of them stay in view: split, group and collapse them, give a group a window of its own, and save windows as workspaces. It takes over sessions running in other terminals, keeps sessions working in the background with a notification when Claude is done or needs you, and resumes every session after a restart. More about what it does.

Latest version: see the release page (release notes). You need Claude Code installed and logged in (claude on your PATH).

Windows

Installer (.exe)

Installs for your user, without admin rights. Updates itself.

Portable (.zip)

Unpack anywhere and start reframe.exe. Keeps its data next to it and tells you about new versions.

For Apple silicon. Built in CI, not tested yet.

Make it executable, then run it. Updates itself.

The first start

The builds are not code-signed yet, so the first start needs a confirmation:

  • Windows installer: if SmartScreen warns, choose More info → Run anyway.
  • Windows, portable: before unpacking, right-click the ZIP → Properties → tick Unblock. Otherwise Windows marks every unpacked file as downloaded, and SmartScreen asks on the first start. The copy keeps its sessions, windows and settings in the folder data next to it and runs apart from an installed reframe. If you let it start with the system and move the folder later, turn that on again.
  • macOS: drag reframe into Applications, then right-click it → Open the first time (or xattr -dr com.apple.quarantine /Applications/reframe.app). Updates on macOS need a signed build, so for now update by downloading the new version.

Uninstall

If you let reframe start with the system, turn that off in the tray menu first (from version 0.6.0 on, the Windows uninstaller does it for you). reframe never changes Claude Code's own settings files, so there is nothing to undo there.

  • Windows installer: Settings → Apps → Installed apps → reframe → Uninstall. Your sessions, windows and settings stay in %APPDATA%\reframe; delete that folder to remove them too.
  • Windows, portable: quit reframe and delete its folder (its data is inside).
  • macOS: quit reframe and move it from Applications to the Trash. Its data is in ~/Library/Application Support/reframe.
  • Linux: delete the AppImage, or remove the package (sudo apt remove reframe). Its data is in ~/.config/reframe.

Code signing policy

reframe uses the SignPath Foundation for code signing: the Windows releases are going to be signed through its free code signing for open source projects (being set up; until then they are unsigned). Free code signing provided by SignPath.io, certificate by SignPath Foundation.
