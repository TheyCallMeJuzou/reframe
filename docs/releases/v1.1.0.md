reframe 1.1 brings the native app to Linux. It does there what 0.10 did, with a fraction of the size, and an AppImage of 0.10 updates to it by itself.

|                    | 0.10 (Electron) | 1.1    |
| ------------------ | --------------- | ------ |
| AppImage           | 128 MB          | 19 MB  |
| Debian package     | 103 MB          | 15 MB  |

Nothing changes on Windows; installed copies update to 1.1 as usual.

## Updating from 0.10 on Linux

The AppImage updates itself as before: it downloads 1.1 and puts it in place when you quit reframe (or right away with _Restart to update_ in the tray menu). Your sessions, windows, groups, workspaces and settings stay as they are (the same `~/.config/reframe`), and so does starting with the system. The sessions resume on the first start, as after any update.

The Debian package is updated by installing the new one over it: `sudo apt install ./reframe_1.1.0_amd64.deb`.

Quit 0.10 before you start 1.1 by hand: both would manage the same sessions, so 1.1 says so and does not start while 0.10 runs.

## Different from 0.10 on Linux

- **Without a tray** (GNOME without its AppIndicator extension, as on Fedora or Debian), a window you close but keep is minimized instead of hidden, so you can still find it. Where there is a tray (KDE, Xfce, Ubuntu's GNOME, …) it waits there as before.
- **Questions and right-click menus** are reframe's own, in the window.
- **On GNOME** reframe draws its own title bar, as GNOME asks of every app on Wayland.
- **On Wayland** a window opens where the desktop puts it (Wayland lets no app choose its place); its size is kept.
- **Files copied** in a file manager are pasted as their paths when `wl-paste` (Wayland) or `xclip` (X11) is installed.

## Known limitations

- Tried in CI and under WSL, not yet on a GNOME or KDE desktop. If something behaves differently than 0.10 did, please [open an issue](https://github.com/TheyCallMeJuzou/reframe/issues).
- It needs a graphics driver with Vulkan or OpenGL ES 3.1 (any current Mesa has one); without one it draws in software, which costs CPU time.
- Screen readers name reframe's buttons, fields, tiles and lists, but not the entries of a choice box while it is open (they can be chosen with the arrow keys).

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in, and Windows 10 or 11, or Linux on x86-64 with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 or later). The builds are not code-signed yet:

- **Windows**: `reframe-Setup-1.1.0.exe` installs for your user, without admin rights, also over an installed 0.x; installed copies update themselves. Or the portable `reframe-1.1.0-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_.
- **Linux**: `reframe-1.1.0-x86_64.AppImage`: make it executable (`chmod +x`) and start it; it updates itself. Or the Debian package, `reframe_1.1.0_amd64.deb`, updated by installing the next one.
- **macOS**: reframe 0.10, from [its release](https://github.com/TheyCallMeJuzou/reframe/releases?q=v0.10).

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
