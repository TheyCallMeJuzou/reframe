Closing a window can now end its sessions too.

## New

- **Closing a window with sessions asks** whether to end them or keep them running in the tray. Until now closing a window only hid it, so its sessions kept running unseen and came back after every restart. _End sessions_ ends them (they stay in the session list, where you can open them again) and the window is gone; the main window stays, empty, in the tray. _Keep in the tray_ hides the window as before. Tick _Don't ask again_ to keep your answer; Settings has the choice too (_Closing a window with sessions_). A window without sessions just closes.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.7.0.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.7.0-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
