Pasting a screenshot on Windows is instant again.

## Fixed

- **Pasting an image on Windows took several seconds.** Ctrl+V with a screenshot on the clipboard left it to Claude Code to read the clipboard, which on Windows took about ten seconds even for a small picture. reframe now saves the image to a file itself and types in its path, as it already did for sessions in WSL, and Claude Code attaches it at once as `[Image #1]`. macOS and Linux are unchanged.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.10.1.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.10.1-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_. An installed and a portable reframe keep their own sessions and settings, but run the same Claude Code: a session one of them runs shows in the other as running elsewhere.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
