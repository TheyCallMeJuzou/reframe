More windows, keyboard shortcuts, files and screenshots, and a session list that does more.

## New

- **New windows**: open a new, empty reframe window from the toolbar, the tray or with Ctrl+Shift+N. Fill it with sessions, move tiles between windows; all of them come back after a restart.
- **Keyboard shortcuts** (Cmd instead of Ctrl on macOS; everything else still goes to Claude Code):
  - Ctrl+1 … 9 focuses a tile by position, Ctrl+Shift+arrow keys the neighboring one
  - Ctrl+Shift+M collapses the focused tile, or brings back the last collapsed one
  - Ctrl+Shift+L shows or hides the session list, with the cursor in its search
  - Ctrl+Shift+T new session, Ctrl+Shift+N new window
- **You see where you type**: the focused tile has an accent frame.
- **Files and screenshots**: drop files onto a session to type in their paths (Claude Code attaches the images among them). Ctrl+V pastes text, files you copied in Explorer or Finder, or a screenshot from the clipboard, which shows up as `[Image #1]`.
- **Session list**:
  - Select several entries with Shift+click (a range) or Ctrl+click, then right-click: open them, open them in a new group, or in a new group in a new window. Dragging a selected entry takes the whole selection along. Sessions running in other terminals are taken over after one question for all of them.
  - Sessions that turn up while reframe runs (started in another terminal, or used again) light up in the list; while the list is hidden, the Sessions button shows a dot.
- **Layout**: new sessions fill two columns in turn: the second goes right of the first, the third below the second, the fourth below the first, and so on.

## Fixed

- The process that runs all sessions could crash now and then when several sessions ended at once, taking every session with it. reframe now uses the newer ConPTY that comes with node-pty (as Windows Terminal and VS Code do).
- On macOS, no session could start ("posix_spawnp failed").
- A session ended by reframe while it was still starting no longer counts as "failed to start".
- Starting the installed app while a development build runs (or the other way round) now says so instead of silently showing the other one.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.2.0.exe` installs for your user, without admin rights; installed copies of 0.1.0 update themselves. If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.
