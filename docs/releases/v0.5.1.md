reframe for Windows also comes portable now: unpack it and start it, no installation.

## New

- **Portable Windows copy** (`reframe-0.5.1-win-portable.zip`): unpack it anywhere (a USB stick, say) and start `reframe.exe`. It keeps its sessions, windows and settings in the folder `data` next to it, so you can take the whole folder along, and it runs apart from an installed reframe, even at the same time. It does not update itself: when there is a new version it tells you, and _Download reframe …_ in the tray menu opens the download page.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.5.1.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.5.1-win-portable.zip`. If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.
