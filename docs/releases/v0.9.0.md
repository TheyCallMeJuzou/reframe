Terminal windows with Claude Code in WSL can be pulled in, starting with the system moves into Settings, and empty windows stay away after a restart.

## New

- **Pull in terminal windows with Claude Code in WSL** (Windows). Drag a Windows Terminal window or tab where `claude` runs in WSL onto reframe, as already worked for one running on Windows: the drop zones show, and after the confirmation the session continues in reframe, in its distribution, at the spot you dropped it. The tab closes if all that is left there is the shell you started `claude` from. Until now, such a drag did nothing.

## Changed

- **"Start with the system" is in Settings** now, with a hint on what happens when you log in. It is no longer in the tray menu.
- **Windows that are empty when reframe quits** (a new window you never used, or the first window once its sessions ended or moved elsewhere) no longer come back empty on the next start. When all of them are empty, one still opens.

## Fixed

- **Ctrl+= Ctrl+= Ctrl+- in quick succession** could leave the text size one step too small.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.9.0.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.9.0-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_. An installed and a portable reframe keep their own sessions and settings, but run the same Claude Code: a session one of them runs shows in the other as running elsewhere.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
