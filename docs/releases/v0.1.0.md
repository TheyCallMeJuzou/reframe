The first release of reframe: your Claude Code sessions side by side in one window, and all of them back after a restart.

## What's in it

- **Tiles, all in view.** Every session is a tile: the first on the left, the next ones stacked on the right. Drag a tile's header onto another tile's edge to put it anywhere; collapse tiles into the side bar and bring them back with a click.
- **Groups**: a colored frame around tiles that belong together, which collapses, moves and leaves the window as one.
- **Several windows**: drag a tile or a group out of the window to give it its own, and back again.
- **Session list**: the sessions in reframe, the ones running in other terminals and your recent Claude Code sessions, with search. Open one with a click or by dragging it; sessions running elsewhere are taken over with their history and name.
- **Pull terminal windows in** (Windows): drag a Windows Terminal or console window, or just one of its tabs, with a running `claude` onto reframe, and the session continues there.
- **Nothing gets lost**: every change is saved; quitting from the tray ends the sessions cleanly, and the next start resumes all of them, each in its folder and its place.
- **In the background**: closing a window only hides it; you get a notification when Claude is done or needs you.
- Starts with the system if you like, updates itself (Windows installer and AppImage), English and German.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.1.0.exe` installs for your user, without admin rights. If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable) or the `.deb`.

## Known limitations

- reframe is developed and tested on Windows. The macOS and Linux builds pass the automated tests but have not been tried by hand yet.
- Pulling terminal windows in works on Windows only; on macOS and Linux, take sessions over from the session list.
- macOS updates need a signed build; until then, download new versions by hand.
