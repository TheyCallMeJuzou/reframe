## Fixed

- **A right-click pasted twice** in Claude Code's fullscreen mode (`"tui": "fullscreen"`), which reads the mouse and pastes on a right-click itself. As in Windows Terminal, a program that reads the mouse now gets the right-click alone: Claude Code copies its own selection or pastes. **Shift+right-click** is reframe's copy and paste there, which also takes files you copied and screenshots. Without fullscreen mode, a right-click works as in 0.8.1.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.8.2.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.8.2-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_. An installed and a portable reframe keep their own sessions and settings, but run the same Claude Code: a session one of them runs shows in the other as running elsewhere.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
