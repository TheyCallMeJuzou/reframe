Save windows as workspaces and come back to them later, and go full screen with F11.

## New

- **Workspaces**: _Workspaces_ in the toolbar saves a window (its tiles, groups, collapsed tiles and size) under a name. Open it again later from the toolbar, the tray or the top of the session list, and it comes back as a window of its own: sessions shown elsewhere move into it, the others resume, even ones you removed from the list since. If its window is still open, that one comes up. Update a workspace from its window, rename or delete it from the session list.
- **Full screen**: F11 takes a window to full screen and back; each window remembers it across restarts. A short hint shows how to leave it, and the toolbar has a button for that meanwhile.

## Fixed

- Sessions opened again right after they were ended (while still on their way out) now start again instead of showing as ended.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.4.0.exe` installs for your user, without admin rights; installed copies update themselves. If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.
