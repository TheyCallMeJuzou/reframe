Windows you closed stay closed.

## Fixed

- Opening reframe while it was already running showed every window, also the ones you had closed, and an empty window you closed was only hidden and kept. So each launch could bring back more and more empty windows. Now a second launch shows the windows that were open (the first one if you had closed them all), an empty window you close is gone for good, and the empty windows older versions kept are cleaned up on the first start. Closed windows with sessions in them stay in the tray as before.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.6.2.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.6.2-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
