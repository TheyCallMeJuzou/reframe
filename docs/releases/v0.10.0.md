The session list shows when each session was last used, so the one you just worked in is easy to find, even among many with the same name.

## New

- **When each session was last used.** Every entry in the session list shows it at the right end of its name: _now_, _5m_, _2h_, _3d_, then the date. Hover an entry for the exact date and time. Sessions in reframe are sorted by it, so the one you just worked in comes first. A prompt counts as using a session, and so does Claude finishing or asking you something; starting reframe (which resumes your sessions) does not. A past session you open from the list keeps the time it was last used, and sessions running in other terminals show theirs too.

## Changed

- **Past sessions in the list** show their time on the right like the others, instead of "5 minutes ago" in the line below.
- Updated dependencies, among them electron-updater 6.8.12 and koffi 3.3.4.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.10.0.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.10.0-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_. An installed and a portable reframe keep their own sessions and settings, but run the same Claude Code: a session one of them runs shows in the other as running elsewhere.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
