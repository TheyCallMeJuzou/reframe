Give your sessions names of your own, and say hello to reframe's About.

## New

- **Rename sessions**: double-click a tile's name, or choose _Rename_ from the right-click menu of a tile or of a session in the session list, and edit the name in place. Enter keeps it, Escape drops it, an empty name goes back to Claude Code's name for the session. The name is reframe's own: Claude Code keeps the one it was started with.
- **About reframe** (the ⓘ in the toolbar, or the tray menu): version, links to reframe on GitHub (a star is very welcome), the license, and who made it.
- **Language**: choose English or German in About, or follow the system's language. It applies right away, everywhere.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.3.0.exe` installs for your user, without admin rights; installed copies update themselves. If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.
