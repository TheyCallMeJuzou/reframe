Claude Code in WSL, separators that line up, and a Settings window.

## New

- **WSL** (Windows): start a session in a folder inside WSL (_Browse…_ → Linux, or type `\\wsl.localhost\Ubuntu\home\…`) and it runs the Claude Code installed in that distribution, shown as `Ubuntu ~/project`. Its status, notifications and resuming after a restart work as for any other session; dropped files and pasted screenshots come in as Linux paths.
- **WSL in the session list**: past sessions of running distributions, and ones running in a WSL terminal, which are taken over like any other. A distribution with Claude Code that is not running says so there, with a button to start it.
- **Snapping**: separators snap to a grid over the window while you drag them, so tiles side by side and in other groups line up. Hold Alt to place one freely.
- **Settings** (the ⚙ in the toolbar, or Ctrl+,): the language (moved here from About), the text size and snapping.
- **Groups grow**: adding a tile that sits right next to a group widens the frame over it instead of moving the tile.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.5.0.exe` installs for your user, without admin rights; installed copies update themselves. If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.
