reframe has a website now, update checks can be turned off, and uninstalling leaves nothing behind.

## New

- **Website**: [theycallmejuzou.github.io/reframe](https://theycallmejuzou.github.io/reframe/), with what reframe does, the downloads for every system, and how to install and uninstall it.
- **Check for updates** (Settings): reframe asks GitHub for a newer version half a minute after starting and then every six hours. That is all it sends on its own, and now you can turn it off. Settings shows it where reframe checks: the Windows installer, the portable copy and the AppImage.

## Fixed

- Uninstalling reframe on Windows left its "Start with the system" entry behind, pointing at the removed program. The uninstaller now removes it (installing a new version over the old one keeps it).

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.6.0.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.6.0-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
