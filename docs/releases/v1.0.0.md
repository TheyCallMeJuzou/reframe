reframe 1.0 is a native Windows app. It does what 0.10 does and looks like it, but it no longer brings a whole browser along: it is written in Rust, starts in a fraction of a second, and needs a fraction of the memory and disk space.

|                                   | 0.10 (Electron)  | 1.0                                                        |
| --------------------------------- | ---------------- | ---------------------------------------------------------- |
| Memory (its own, three sessions)  | 161 MB           | 23 MB                                                      |
| On disk                           | 340 MB           | 32 MB (the installer: 8 MB)                                |
| Idle, three sessions              | 1.9 % of a core  | about 1 % while the cursor blinks in the window in front, nearly nothing otherwise |

## Updating from 0.x

An installed 0.x updates itself as usual: it downloads 1.0 and installs it when you quit reframe (or right away with _Restart to update_ in the tray menu). Your sessions, windows, groups, workspaces and settings stay as they are (same profile, same file), and so do your shortcuts and starting with the system. The sessions resume on the first start, as after any update.

## Changed

- **Windows only, for now.** macOS and Linux keep reframe 0.10; their copies do not update to 1.0. The 0.10 downloads stay on [its release](https://github.com/TheyCallMeJuzou/reframe/releases?q=v0.10) and on the website.
- **Faster and smaller**, see above. The window is drawn by the GPU, and only when something changed in it.

Everything else is as in 0.10, also the shortcuts, the texts, the windows' sizes and where reframe keeps its data. If something behaves differently than it did, please [open an issue](https://github.com/TheyCallMeJuzou/reframe/issues).

## Looks a little different

- **Terminal text** is laid out by Windows itself (DirectWrite, like Windows Terminal). At 100 % display scaling it runs a little wider than in 0.10, so a tile fits a few columns less.
- **Right-click menus** are Windows' own, in the system's light or dark mode as before, a little more compact than 0.10's.
- **Checkboxes** are ticked in reframe's accent colour.

## Known limitations

- Screen readers name reframe's buttons, fields, tiles and lists, but not the entries of a choice box while it is open (they can be chosen with the arrow keys).

## Install

You need Windows 10 or 11 and [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-1.0.0.exe` installs for your user, without admin rights, also over an installed 0.x; installed copies update themselves. Or the portable `reframe-1.0.0-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_. An installed and a portable reframe keep their own sessions and settings, but run the same Claude Code: a session one of them runs shows in the other as running elsewhere.
- **macOS and Linux**: reframe 0.10, from [its release](https://github.com/TheyCallMeJuzou/reframe/releases?q=v0.10).

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
