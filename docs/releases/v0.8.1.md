Right-click to copy and paste in a session, and a terminal window dropped onto a window in front lands there.

## New

- **Right-click in a session** copies the selected text and clears the selection; with nothing selected, it pastes like Ctrl+V: text, files you copied in Explorer or Finder (as their paths), or a screenshot. As in Windows Terminal, and the same on macOS and Linux.

## Fixed

- **A terminal window or tab dropped onto reframe** (Windows) where two reframe windows overlap, onto a new window opened over the main one, say, went into the window opened first, in between its tiles, and the drop zones showed there too, out of sight. It now goes into the window in front.
- **Ctrl+Shift+Space or a notification** sometimes brought a collapsed session back without putting you into it: when its tile took a moment to show, the focus went nowhere. It now waits for the tile.

## Install

You need [Claude Code](https://claude.com/claude-code) installed and logged in: on Windows itself, or in WSL for sessions in WSL folders. The builds are not code-signed yet:

- **Windows**: `reframe-Setup-0.8.1.exe` installs for your user, without admin rights; installed copies update themselves. Or the portable `reframe-0.8.1-win-portable.zip` (right-click it → _Properties_ → _Unblock_ before unpacking). If SmartScreen warns, choose _More info_ → _Run anyway_. An installed and a portable reframe keep their own sessions and settings, but run the same Claude Code: a session one of them runs shows in the other as running elsewhere.
- **macOS** (Apple silicon): open the `.dmg` and drag reframe into Applications; the first time, right-click it → _Open_.
- **Linux**: the `.AppImage` (make it executable; it updates itself) or the `.deb`.

How to uninstall: [on the website](https://theycallmejuzou.github.io/reframe/download.html#uninstall). Windows releases are going to be signed through the SignPath Foundation: [code signing policy](https://theycallmejuzou.github.io/reframe/code-signing.html).
